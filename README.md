恢复教学大纲 PDF 下载按钮，并查询未选课程大纲的 Chrome 扩展。

> 本项目是非官方工具，与西湖大学及其教学系统开发方无关。

## 功能

- 在教学大纲 PDF 预览器中恢复原生下载按钮。
- 同时支持 PDF.js 主工具栏和次级工具栏中的保存入口。
- 在“我的课表”中增加独立的未选课程大纲查询面板，按课程名称、代码、教学班或教师筛选。
- 从学期选项加载已核实的课程目录，逐门查询大纲附件，支持中英文附件和在线大纲链接。
- 支持收起、展开已加载的目录，保留搜索条件和查询结果。
- 仅在教学大纲预览器和“我的课表”运行。
- 无后台服务、无第三方运行时依赖。

## 工作原理

教学系统使用 PDF.js 展示教学大纲，并通过页面参数隐藏原有保存按钮。下载功能恢复 PDF.js 已有的下载控件。扩展不拦截网络请求，也不绕过登录或访问控制。

未选课程查询读取教学系统发布的课程索引，再使用系统大纲详情页自身调用的只读接口取得附件链接。部分附件型大纲的详情页会因缺少 `structuredDocument.paragraphs` 报错；扩展直接展示附件链接，避免依赖这个出错的页面。

课程目录在系统内部按选课批次发布，扩展将已核实的编号映射为学期选项，用户无需查找或输入编号。目前已核实的选项为 **2026 年第 1 学期**（内部编号 `121`），包含 271 个教学班、190 个课程代码。历史目录尚未核实，不显示未经确认的学期，也不保证涵盖所有学期、所有课程。大纲是否上传及当前账号能否读取，仍由教学系统决定；目录加载成功不代表每门课都有可下载的大纲。

## 安装

### 从源码安装

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录。

安装后如果修改了代码，请在扩展管理页点击“重新加载”。

## 使用

1. 打开课程列表中的“教学大纲”。
2. 在 PDF 预览器工具栏中点击“下载教学大纲”。

下载由 PDF.js 和 Chrome 原生下载流程处理。

### 选课关闭后的已选课程

系统已有入口：**全部服务 → 我的课表 → 全部课程 → 教学大纲**。这里的“全部课程”指本人已选课程。扩展不重复添加该入口。

### 未选课程大纲

1. 登录教学系统，打开“我的课表”。
2. 展开页面顶部的“查询未选课程的大纲”。
3. 选择学期，点击“加载课程目录”。当前提供已核实的“2026 年第 1 学期”。
4. 输入课程名称、课程代码或教师姓名。
5. 在目标教学班旁点击“查询大纲”，再打开返回的中文附件、英文附件或在线大纲。
6. PDF 附件加载后，使用预览器中的“下载教学大纲”按钮保存。

点击“查询未选课程的大纲”标题栏可收起或展开整个查询面板，右侧显示“展开 / 收起”提示。搜索条件、筛选结果和已查询的附件链接会保留，无需重新加载；加载期间收起面板也不会在请求完成后自动展开。

目录和大纲资料只在点击加载或查询按钮时读取，不自动遍历所有大纲、不执行选课或退课。页面仅显示前 40 条匹配结果，可进一步搜索定位其他课程。

## 权限与隐私

扩展不会：

- 读取或保存账号、密码和 Cookie；
- 自动读取、上传或分析教学大纲文件内容；
- 向教学系统以外的服务器发送数据；
- 在其他网站运行。

查询面板使用当前浏览器登录会话向教学系统发送只读请求，读取课程目录和大纲附件链接。它不读取 Cookie 的值，课程目录、搜索条件和附件链接仅保留在当前页面内存中，不写入持久存储。扩展无需 `cookies`、`storage`、`tabs` 或 `downloads` 权限。

## 开发

### 项目结构

```text
.
├── manifest.json          # Chrome 扩展清单
├── src/
│   ├── content.js         # 恢复 PDF.js 下载按钮
│   ├── catalog-data.js    # 课程目录和大纲只读查询
│   ├── catalog.js         # 未选课程查询面板
│   └── catalog.css        # 面板样式
└── tests/
    └── catalog-data.test.cjs
```

项目没有构建步骤或第三方依赖。修改代码后，在 `chrome://extensions/` 中重新加载扩展，并刷新教学系统页面。

数据查询逻辑可用 Node.js 22 或更新版本检查：`node --test tests/catalog-data.test.cjs`。

### 手动验证

1. 打开一个教学大纲预览。
2. 确认工具栏出现“下载教学大纲”按钮。
3. 点击按钮并确认 PDF 可以正常保存。
4. 在我的课表加载未选课程目录，按名称、代码和教师分别搜索。
5. 选择未选课程，验证附件链接是否打开对应教学班的大纲；有中英文附件时分别检查。
6. 检查缺少大纲、未登录、目录不存在和网络失败时的提示。
7. 点击标题栏收起并重新展开面板，确认搜索条件、筛选结果和已查询的附件链接保留；折叠操作不触发额外请求。

2026-09-30 实测：批次 `121` 返回 271 个教学班；未选课程《抽象代数（上）》中文大纲正常打开（3 页），《偏微分方程》英文大纲正常打开（5 页），两者均返回中英文附件链接，PDF 下载按钮正常显示。

## 故障排查

### 看不到下载按钮

1. 在 `chrome://extensions/` 确认“西湖教学大纲下载器”存在且已启用；找不到时，按上文“从源码安装”重新加载本仓库目录。
2. 在 `chrome://extensions/` 中重新加载扩展。
3. 关闭教学大纲弹窗后重新打开。
4. 刷新教学系统页面后重试。

### 点击按钮后没有下载

确认教学大纲已经在预览器中正常加载。如果 PDF 本身无法显示，本扩展也无法获取该文件。

### 查询面板不出现

重新加载扩展后刷新“我的课表”。此面板只出现在课表页面，不会添加到选课关闭提示页或 PDF 预览器中。

### 任意课程查询受限

下拉选项只包含已核实可用的学期目录，尚未核实的历史目录不会显示。如果接口返回无权限、登录失效或课程没有大纲，面板会显示原因，不会把课程目录当成已下载的大纲。
