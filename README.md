# 西湖教学大纲下载器

一个最小权限的 Chrome Manifest V3 插件，用于在西湖大学教学系统的教学大纲 PDF 预览器中恢复“下载教学大纲”按钮。

## 工作方式

教学系统使用 PDF.js 展示教学大纲，并通过页面参数隐藏原有保存按钮。插件只在该 PDF.js 预览页面运行，恢复现有按钮，不读取账号、Cookie 或教学大纲内容，也不向外部服务器发送数据。

## 本地安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库文件夹。
5. 重新打开教学大纲预览；工具栏右侧会出现“下载教学大纲”按钮。

修改代码后，在扩展管理页点击此插件的“重新加载”即可更新。
